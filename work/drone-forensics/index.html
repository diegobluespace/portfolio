CASE STUDY

드론 포렌식 솔루션

3분 걸리던 핵심 기능을 약 60ms로. 1년 계획을 6개월에 끝낸 제품 개발 전 과정.

  • 핵심 기능 처리 시간약 3분→약 60ms약 3,000배
  • 개발 기간12개월 계획→6개월 완료50% 단축

개요

수사·보안 분야에서 불법 비행을 탐지하고 디지털 증거를 확보하기 위한 솔루션입니다. 드론 기체, 컨트롤러, 외장 매체, 앱에 저장된 데이터를 복구해 저장하고 보고서로 출력합니다. GPS 기반 비행 기록 로그를 분석해 뷰어에서 재생하고, 사고 원인 분석과 미디어 미리보기를 제공합니다.

문제

QA와 고객에게서 “기능 동작 속도가 매우 느리다“는 피드백이 반복해서 들어왔습니다. 핵심 기능 하나를 실행하는 데 약 3분이 걸렸고, 그동안 사용자는 기다릴 수밖에 없었습니다.

접근

  • 느린 핵심 로직을 UI 프로세스에서 떼어내 별도 백그라운드 프로세스(AOT 콘솔 프로그램)로 분리했습니다.
  • 분리한 모듈을 리팩토링·최적화하고 AOT(Ahead-of-Time) 빌드를 적용했습니다. 실행 시 JIT 비용이 사라졌고, 디컴파일 방지 효과도 함께 얻었습니다.
  • 화면은 MVVM 구조로 정리해 분석 결과가 준비되는 대로 반영되도록 했습니다.

함께 개선한 것

  • CI/CD: TeamCity로 빌드·패키징·배포를 자동화했습니다.
  • 협업 환경: SVN에서 GitLab으로 옮겨 코드 리뷰 절차를 단축했습니다.
  • 기능: FFmpeg 기반 화면 녹화, 파일 포맷을 분석해 로그로 변환하는 분석 기능을 개발했습니다.

결과

  • 핵심 기능 처리 시간 약 3분 → 약 60ms, 약 3,000배 개선
  • 약 1년으로 잡혀 있던 개발 계획을 6개월 만에 완료

맡은 범위

2022년 말 제품을 1인 담당으로 인수한 뒤, 기획 회의 진행과 Figma 디자인, 개발, 성능 개선, CI/CD, 고객 문의 대응과 일정 관리까지 제품 운영 전반을 맡았습니다.
