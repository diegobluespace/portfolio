PERSONAL PROJECT

Bedside Text-to-Speech Web App

I built this for a friend’s parent. To help a patient who could not speak communicate with caregivers, I built a web app that reads a sentence aloud with one tap.

Why I built it

When I met an old friend, I learned that a family member of theirs was in the hospital and could barely speak, which made talking with caregivers very hard. I thought a tablet that speaks the right sentence with a single tap could help, so I built one.

Features

  • Tap a button and Google TTS reads the saved sentence aloud.
  • Tap edit and the button turns into a text field, so the sentence can be changed on the spot.

Why the web

  • Device-independent: works on any device
  • No install: nothing to download
  • Easy access: one link is all it takes
